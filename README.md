Predictive Analytics & NLP

* Models fine-tuned or indexed from public datasets, covering predictive analytics, NLP, generative AI, and multimodal systems.

Contents

* Predictive Modeling/ — Fraud detection, stock and financial time series forecasting, engagement recommendation, and clustering notebooks (Fraud_detection.ipynb, Apple_Stock_prediction_timeseries_split.ipynb, Time_Series_Financial_NYSE.ipynb, Engagement_Recommendation_Markov.ipynb, Unsupervised_learning_Clustering_Credit_Card_Analysis.ipynb).
* NLP/ — Natural language processing notebooks and scripts.
* Transformer/ — Transformer-based model implementations, including vision and diffusion transformers (visual_transformer_and_cnn.py).
* project/ — Supporting project files.
* data/ — Datasets sourced from Kaggle and Hugging Face.


Highlights

* Notebooks covering image generation, model fine-tuning, multimodal chatbots, and predictive analytics.
* Built with TensorFlow, PyTorch, scikit-learn, pandas, NumPy, seaborn, and matplotlib.
* Datasets sourced from Kaggle and Hugging Face.
* Transformer and diffusion transformer architectures, including Vision Transformers (ViT), audio transformers (OpenAI Whisper), CNNs, and BERT.
* Deep learning with Keras and PyTorch.
* Deployment via Hugging Face Spaces and Gradio UI.
* Generative AI and agentic systems using RAG, autonomous agents, vector databases, and prompt engineering.
